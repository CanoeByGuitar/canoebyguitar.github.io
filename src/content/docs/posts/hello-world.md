欢迎来到我的像素乐园。这是一个用 **Astro + Starlight** 搭建的个人博客，采用卡通像素风格，并支持深色与浅色主题切换。

## 它能做什么

- 用 Markdown 写文章
- 深色 / 浅色主题一键切换
- 响应式排版
- 后续可扩展流程图、数学动画和交互组件

## 一段代码

```ts
export function greet(name: string) {
  return `你好，${name}！`;
}
```
